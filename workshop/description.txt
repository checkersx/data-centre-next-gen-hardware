Adds [b]Gen 2, Gen 3 and Gen 4[/b] versions of every server to the shop, plus a new switch with both copper and fibre ports.

Late in the game, a big customer means filling rack after rack with the same 3U servers and cabling every one. Next-Gen servers do that job in less space with fewer cables. They cost more money and XP, so the normal servers are still worth buying early on.

[h2]⚠ This is a code mod: pick an install method below[/h2]
Data Center doesn't install code mods by itself. With [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830456292]WorkshopModSync[/url] (a free helper by Bloody) it's subscribe and play. Without it, there's one file to copy. Both are explained under [b]How to install[/b].

[h2]Before you install (once, for any code mod)[/h2]
If you already use other code mods, you most likely have these. Otherwise:
[olist]
[*][b]MelonLoader 0.7.3[/b] from [url=https://github.com/LavaGang/MelonLoader/releases]the MelonLoader releases page[/url]. Run the installer, point it at Data Center.exe, choose 0.7.3, install. Start the game once, then quit.
[*][b]A fix-up plugin[/b], or no code mods load at all: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3797166996]DS-InteropFix[/url] or [url=https://github.com/mleem97/Il2CppAssemblyFixer]Il2CppAssemblyFixer[/url]. Follow its own instructions.
[/olist]

[h2]How to install: pick one[/h2]
All four ways start from your [b]game folder[/b]. To open it: in your Steam Library, right-click [b]Data Center[/b] → [b]Manage[/b] → [b]Browse local files[/b]. It's the folder with [b]Data Center.exe[/b] in it.

[h3]Way 1: you already have WorkshopModSync (easiest)[/h3]
Check: if the [b]Plugins[/b] folder in your game folder contains [b]WorkshopModSync.dll[/b], you have it.
[olist]
[*]Subscribe to this mod.
[*]Start the game. Done. WorkshopModSync installs your subscribed mods every time the game starts, updates included.
[/olist]

[h3]Way 2: set up WorkshopModSync once, then subscribe and play[/h3]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830456292]WorkshopModSync[/url] is a free helper made by [b]Bloody[/b]. Set it up once, and this mod and other Workshop code mods install and update themselves. It can't install itself, so:
[olist]
[*]Close the game, then subscribe to [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830456292]WorkshopModSync[/url] and to this mod.
[*]Set up WorkshopModSync by following [b]Set it up once[/b] on [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3830456292]its page[/url]. It comes with a one-click installer ([b]WorkshopModSyncInstaller.exe[/b]) that finds Data Center and puts it in the right place.
[*]Start the game. Done. This mod installs itself and stays up to date.
[/olist]

[h3]Way 3: copy one file by hand (no helper)[/h3]
Data Center downloads Workshop mods into a folder of its own, which MelonLoader doesn't look in, so copy the file across once:
[olist]
[*]Subscribe to this mod.
[*]Start the game, wait for the main menu, then quit.
[*]In your game folder, open [b]Data Center_Data[/b] → [b]StreamingAssets[/b] → [b]Mods[/b] → [b]workshop_3829635443[/b] → [b]Mods[/b], and copy [b]NextGenHardware.dll[/b].
[*]Go back to your game folder, open its [b]Mods[/b] folder, and paste.
[*]Start the game.
[/olist]

[h3]Way 4: without the Steam Workshop[/h3]
Download [b]NextGenHardware.dll[/b] from the [url=https://github.com/checkersx/data-centre-next-gen-hardware/releases]GitHub releases page[/url] and put it in the [b]Mods[/b] folder in your game folder.

[b]Check it worked:[/b] the MelonLoader console shows [b]Next-Gen Hardware v1.1.0[/b], and the shop has "Gen 2", "Gen 3" and "Gen 4" servers.
[b]Had "New Servers"?[/b] That's this mod's old name. Delete [b]NewServers.dll[/b] from your Mods folder. Your unlocks and servers carry over.

[h2]Using Gen 3 and Gen 4 servers[/h2]
Their SFP slots need a module before a cable connects, just like the fibre switches. Buy a box of SFP modules, hold it, click a slot to insert a module, then plug in a cable. Any module type is fast enough. [b]SFP RJ45[/b] takes an ordinary copper cable.

[h2]"New subnet" service requests count IOPS[/h2]
These used to ask for a number of servers, so you had to rack cheap ones just to make up the count. Now they ask for [b]5,000 IOPS per server[/b]: 20 servers becomes 100,000 IOPS, which one Gen 4 7U and two Gen 3 3Us cover. Servers count as before (set to that customer, with an IP in the new subnet), at their listed IOPS.
[b]To turn it off:[/b] close the game, open [b]UserData\MelonPreferences.cfg[/b] in your game folder, and under [noparse][NextGenHardware][/noparse] change [b]ServiceRequestsCountIops = true[/b] to [b]false[/b].

[h2]Saves[/h2]
[list]
[*]Saves stay vanilla. Upgraded hardware is saved as its normal version, and a small [i].newservers.json[/i] file next to the save remembers the upgrades.
[*]Remove the mod and your saves still load: upgrades become normal servers, the new switch becomes a starter switch, and cables in SFP slots are lost (re-cable those servers).
[*]Without the mod, a request met on IOPS with fewer servers than it names goes back to In Progress (you keep the reward).
[*]Rack templates don't support upgraded hardware yet.
[/list]

[h2]Co-op[/h2]
[b]Never tested.[/b] It should work in theory, as long as every player has the mod at the same version.

[h2]Updating and uninstalling[/h2]
[list]
[*][b]Update with WorkshopModSync:[/b] nothing to do. The update installs the next time you start the game.
[*][b]Update without it:[/b] Steam downloads updates automatically. Copy the new NextGenHardware.dll across again (Way 3, steps 2–4).
[*][b]Uninstall:[/b] with the game closed, unsubscribe first (so WorkshopModSync doesn't put it back), then delete NextGenHardware.dll from the game's Mods folder.
[/list]
